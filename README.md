## Overview

This project analyses the socio-demographic structure of Spain's 8,131 municipalities alongside their electoral outcomes in the November 2019 and July 2023 general elections. Using official open data from Spanish public institutions, a unified municipal-level dataset was constructed from scratch, integrating geographic, demographic, economic, and electoral variables. Several unsupervised clustering algorithms are then applied and compared — including K-Means, Spectral Clustering, Agglomerative Hierarchical Clustering, DBSCAN, Gaussian Mixture Models, and a custom PyTorch implementation of Deep Embedded Clustering (DEC) — to identify interpretable socio-demographic and electoral typologies of Spanish municipalities.

## Source Files

- **`src/config.py`** — Central configuration file. Defines all variable names as constants, file paths, party colour schemes, official national electoral results, and CCAA codes. Imported across the pipeline to ensure consistent naming.

- **`src/data_extraction.py`** — Full data extraction and harmonisation pipeline. Reads raw files from `data/raw/`, resolves municipal code inconsistencies across sources, constructs electoral proxies for coalition comparisons (Sumar 2019 proxy, NA+ handling), and outputs the final GeoDataFrame to `data/processed/`.

- **`src/clustering.py`** — Clustering utilities. Includes `preprocess_data` (standard scaling and NaN handling), `perform_clustering` (a unified interface for all six algorithms), `evaluate_clusters` (Silhouette, Davies-Bouldin, Calinski-Harabasz), `compute_centroids`, `plot_cluster_map` (choropleth with Canarias/Ceuta/Melilla insets), and `plot_cluster_scatter`.

- **`src/DEC.py`** — Custom implementation of Deep Embedded Clustering in PyTorch, adapted from Xie et al. (2016) and Guo et al. (2017). Includes the stacked autoencoder (`Autoencoder`), the Student's t-distribution clustering layer (`ClusteringLayer`), the combined model (`DECModel`), and the `DEC` class with a `fit_predict` interface matching scikit-learn conventions. Training proceeds in two phases: autoencoder pre-training via MSE, followed by joint optimisation using MSE and KL divergence.

## Notebooks

The notebooks must be run in order.

- **`01_data_extraction.ipynb`** — Data extraction and harmonisation. Applies all six algorithms to both the socio-demographic and electoral variable groups across various parameter configurations, evaluates performance metrics, and visualises the resulting cluster maps. ## Dependencies

The project uses Python 3 with a conda environment. An `environment.yml` file is provided in the repository. It includes all required dependencies: `pytorch`, `pytorch-cuda`, `geopandas`, `scikit-learn`, `pandas`, `matplotlib`, `seaborn`, `plotly`, `jupyterlab`, `openpyxl`, `ipywidgets`, `torchvision`, and `tqdm`.

To create and activate the environment:

```bash
conda env create -f environment.yml
conda activate tfgGPU
```

> **Note:** The environment is configured for GPU support via `pytorch-cuda`. If you do not have a CUDA-compatible GPU, replace `pytorch-cuda` and `pytorch` in `environment.yml` with the CPU-only PyTorch package before creating the environment. The code will fall back to CPU automatically, but DEC training will be significantly slower.

## Methodology Notes

- All clustering was performed on standardised data (zero mean, unit variance). PCA was evaluated but discarded due to the low dimensionality of the feature sets.
- Variables were divided into two groups: **socio-demographic** (8 variables) and **electoral** (8 variables), clustered separately.
- Evaluation used the Silhouette Score, Davies-Bouldin Index, and Calinski-Harabasz Index as secondary indicators, with qualitative interpretability as the primary criterion.
- The DEC implementation follows the architecture of Xie et al. (2016) with enhancements from Guo et al. (2017), simplified for the lower dimensionality of this dataset.
